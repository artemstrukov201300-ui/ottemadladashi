ТЁМА × ДАША — инструкция

Локальный запуск на компьютере:
1. Установи Python 3.
2. Открой терминал в папке проекта.
3. Выполни:
   python -m venv .venv
   .venv\Scripts\activate       (Windows)
   pip install -r requirements.txt
   python app.py
4. Открой http://127.0.0.1:5000

Чтобы Даша могла открыть сайт по ссылке и QR-коду:
1. Размести папку проекта на хостинге Python/Flask (например, Render).
2. Команда запуска: gunicorn app:app
3. После публикации открой публичный адрес сайта и добавь /qr.png — получишь QR-код.
   Например: https://твой-адрес/qr.png
4. QR-код из локальной версии (127.0.0.1) не будет работать у Даши — нужен опубликованный адрес.
